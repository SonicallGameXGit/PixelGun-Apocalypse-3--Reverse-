# docs/

Distilled, evidence-backed knowledge about the original game. Keep each claim labelled as **observed**, **inferred** or **unknown**, with a pointer to the evidence (REA evidence ID, capture file, or asset path).

Planned documents:

- `architecture.md`: stack decisions (windowing, math crate, physics, audio) and rationale.
- `original-build.md`: structure of the Unity WebGL build (files, Unity version, compression, scenes).
- `protocol.md`: multiplayer protocol of the original servers.
- `gameplay/`: weapons, movement, modes, progression, balance tables.
- `assets.md`: asset extraction pipeline and manifest format.
- `unknowns.md`: open questions and what is needed to resolve them.
